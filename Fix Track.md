# FixTrack — Complete HTML + CSS Multi-Page Demo

## Pages
1. Issue Board
2. Report Issue
3. Possible Duplicate
4. Waiting Line
5. Assigned Work
6. Verify Fix
7. Issue Detail
8. Maintenance Analytics
9. Billing & Contractor Settlement

Every page has its own `index.html` and `style.css`.

## Added in this version
- CSS-only working hamburger side menu.
- CSS-only light/dark mode.
- Native HTML dropdown menus using `<details>`.
- Select dropdown filters on analytics and billing.
- Linked navigation between all pages.
- Issue detail timeline, SLA, assignment and activity.
- Analytics KPI cards, bar chart, category progress bars and staff workload table.
- Billing settlement, payment methods, invoice details and recent settlements.
- Responsive desktop/tablet/mobile layouts.
- No JavaScript required.

## Bill Printing
The Billing & Contractor Settlement page includes **Print / Save Bill**.
Click it and use the browser print dialog's **Save as PDF** option to download
the bill as a PDF. Print CSS hides the navigation and payment controls and
formats the bill for A4 paper.
